# Register-Debug
Cheat Engine Non-interrupting register debugger (Cheat Engine非中断型寄存器调试器)
EN:This is a debugger that won't trigger interrupts. Enter the instruction address of the program that's currently attached, and it can get the values of all registers. If a register has changed, it will turn red; if it hasn't, it will stay green.
CN:这是一个不会触发中断的调试器,输入当前已经附加的程序指令地址,他可以获取所有寄存器的值,如果是有变化的,寄存器会变红色,如果是不变的,他会保持绿色
